# Release Checklist

## Collection readiness
- [ ] Release scope and version are declared.
- [ ] Every included collector ID exists in the approved registry.
- [ ] No duplicate collector IDs or titles remain unresolved.
- [ ] All included card packages pass their review checklist.

## Content review
- [ ] Theology review is approved.
- [ ] Scripture references are verified.
- [ ] Gameplay language is consistent and testable.
- [ ] Artwork direction contains no unsupported biblical claims.

## Generated assets
- [ ] Prompt compilation inputs are approved.
- [ ] Generation metadata is recorded.
- [ ] Final image and card layout are approved.
- [ ] Print dimensions, bleed, safe area, and resolution pass QA.
- [ ] Web/mobile derivatives are generated from the approved master.

## Traceability
- [ ] Generated artifact manifest maps outputs to source versions.
- [ ] Revision history is current.
- [ ] Release notes identify intentional changes.
- [ ] Superseded files are clearly marked and excluded.
