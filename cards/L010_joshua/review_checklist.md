# Joshua Review Checklist

This package checklist supplements the mandatory [Production Validation Standard](../../docs/PRODUCTION_VALIDATION_STANDARD.md) and [Artwork Review Standard](../../docs/ARTWORK_REVIEW_STANDARD.md). Checkboxes record evidence gathering; approvals require named version/hash decisions in the relevant gate record.

Unchecked items require human review; completion of source authoring is not approval.

## Package and traceability
- [x] Collector ID, name, title, set, and versions are internally consistent.
- [x] Scripture, inference, tradition, and project interpretation are labeled.
- [x] Major passages and New Testament references are inventoried.
- [x] Source files and generated prompt manifest cross-reference versions.
- [x] Every compiled prompt sentence and negative-prompt group has recorded provenance.
- [x] Independent package, prompt, artwork, layout, print, and metadata versions are represented.
- [x] Generation is explicitly blocked until adapter/model/settings and G1–G4 approvals are recorded.
- [ ] Biblical/theological reviewer approves claims and conquest framing.

## Gameplay
- [x] Strategic identity is distinct from Moses and Caleb.
- [x] Mechanics remain philosophical and unbalanced.
- [x] Divine acts are not intrinsic magic controlled by Joshua.
- [ ] Gameplay reviewer approves candidate mechanic families.

## Prompt and art direction
- [x] Prompt follows canonical grammar order and has one narrative mode.
- [x] Age is presented as project direction, not canonical fact.
- [x] Composition, lighting, materials, silhouette, and 2:3 output are defined.
- [x] Jericho is intact in the selected pre-fall scene.
- [x] Ark is carried by priests, closed, subordinate, and not weaponized.
- [x] No fantasy, medieval, Roman, magical, triumphalist, or caricature direction.
- [ ] Art director approves source prompt before generation.

## Generated-output inspection (not yet applicable)
- [ ] Face and expression match Joshua's identity.
- [ ] Hands, fingers, limbs, sword grip/scabbard, feet, and anatomy are sound.
- [ ] Ark, carrying poles, trumpets, procession, architecture, and scale are coherent.
- [ ] Silhouette and focal hierarchy read at card thumbnail size.
- [ ] Overlay-safe areas work in the official card layout.
- [ ] No embedded text, pseudo-script, signature, watermark, or artifact.
- [ ] Historical plausibility and respectful human depiction pass review.
- [ ] Generation model, adapter, seed/job ID, dimensions, date, and output hash are recorded.
- [ ] Final artwork and card layout receive separate approval.

## Phase 4 pre-generation evidence

No item below constitutes approval until a named reviewer records a dated decision in canonical `review.yaml`.

- Biblical/theological: divine authority and agency; respectful Ark treatment; no prohibited sacred depiction; fact/inference/reconstruction/project-interpretation separation; scene supported without invented event claims.
- Historical: clothing, sword, architecture, terrain, procession, materials, hierarchy, and military language; uncertainty remains classified as reconstruction.
- Gameplay: ordered courage, obedience, leadership, inheritance, and covenant responsibility; differentiation from Moses, Caleb, David, and Gideon; no magical control of God or sacred objects.
- Art direction: silhouette, card-safe framing, face and gesture, restrained detail, historically plausible equipment, no fantasy language, reusable continuity.
- Prompt: every compiled clause is accounted for by canonical fields, shared standards, grammar, or negative sources; classifications remain visible.
