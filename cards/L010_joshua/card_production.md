# Joshua Card Production

This stage cannot begin until an exact Joshua artwork hash passes G5. Follow the shared [card production sequence](../../docs/PRODUCTION_VALIDATION_STANDARD.md#card-production-sequence).

| Step | Joshua input | Artifact/evidence | Blocking review |
|---:|---|---|---|
| 1. Artwork | G5-approved `L010-JOSHUA-ART-01` version/hash | Imported linked master; hash verification | No substitution, destructive stretch, or unrecorded crop. |
| 2. Overlay-safe placement | canonical `art.yaml` focal point and safe zones | Crop/placement record | Face, signal hand, sword, and required background story survive frame. |
| 3. Card frame | Approved Core Legendary frame/version | Layered layout source | Correct Legendary treatment and set consistency. |
| 4. Typography | Governed styles | Typography proof | Joshua/name/title readable; no generated-image typography. |
| 5. Ability box | Reviewed canonical `gameplay.yaml` and final rules source | Rules-copy record | “Walls Fall Down” wording is approved, legible, and does not assign personal magic. |
| 6. Flavor text | Direct Scripture quotation with translation/license metadata, or labeled approved project copy | Citation/copy record | No fabricated quotation or ambiguous Scripture attribution. |
| 7. Collector metadata | Registry `L010`, set code, rarity, versions | Data validation report | Registry and rendered data match exactly. |
| 8. QR/metadata | Approved durable destination, or intentional omission | Link/contrast/privacy record | QR quiet zone, longevity, privacy, and offline failure considered. |
| 9. Print geometry | Future official print specification | Trim/safe/bleed overlay | Production is blocked while a required print specification/profile is absent. |
| 10. Export | One approved layout source | Digital render, print render, layout/print manifests and hashes | Export presets, colour profile, fonts, resolution, and bytes recorded. |
| 11. QA/release | G6 proof and G7 evidence | Preflight, proof, release bundle | All checks and named approvals complete. |

No ability rules text, flavor text, QR destination, official frame version, or print dimensions are invented by this package. Their absence is an explicit downstream dependency, not permission to choose ad hoc values.
